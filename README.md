# Factory_Logic

Учебный проект по Python Backend, построенный по принципам, максимально приближенным к промышленной разработке.

## О проекте

Factory_Logic — это справочник ошибок и параметров частотных преобразователей с возможностью поиска через различные интерфейсы.

Сейчас реализован CLI-интерфейс. В дальнейшем проект будет развиваться как единое ядро приложения с несколькими интерфейсами взаимодействия.

Проект создаётся не как одноразовое учебное задание, а как основа для портфолио и изучения архитектуры Python-приложений.

---

## Возможности

* поиск ошибки по коду;
* вывод информации об ошибке;
* работа с данными из JSON;
* разделение проекта на слои;
* единая бизнес-логика независимо от интерфейса.

---

## Структура проекта

```text
app/
├── data/               # данные (faults.json)
├── formatters/         # форматирование вывода
├── interfaces/
│   ├── cli/            # консольный интерфейс
│   └── max_bot/        # интерфейс MAX Bot
├── repositories/       # работа с источниками данных
├── services/           # бизнес-логика
├── config.py
└── main.py

tests/
```

## Установка

### Windows (PowerShell)

**Создание виртуального окружения**

```powershell
python -m venv .venv
```

**Активация виртуального окружения**

```powershell
.venv\Scripts\Activate.ps1
```

**Установка зависимостей**

```powershell
pip install -r requirements.txt
```

---

### Linux

**Создание виртуального окружения**

```bash
python3 -m venv .venv
```

**Активация виртуального окружения**

```bash
source .venv/bin/activate
```

**Установка зависимостей**

```bash
pip install -r requirements.txt
```

## Архитектура

Проект разделён на независимые слои:

* **interfaces** — взаимодействие с пользователем;
* **services** — бизнес-логика;
* **repositories** — получение данных;
* **data** — хранение данных;
* **formatters** — подготовка информации для вывода.

Такой подход позволяет добавлять новые интерфейсы (Telegram, MAX, Web API, GUI) без изменения основной логики приложения.
